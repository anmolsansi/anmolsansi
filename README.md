### 🔹 [RecollectFlow](https://github.com/anmolsansi/Recollect-Flow) — Private Capture & Recall System

> A private, zero-cost-first system for durably capturing URLs, text, and notes before optional enrichment and future grounded retrieval.

- Built the current capture slice around durable raw-source persistence before downstream processing.
- Uses idempotent capture semantics so retries do not silently duplicate user data.
- Separates foundational capture from future AI/RAG capabilities so semantic features do not become a dependency for trustworthy storage.
- Maintains explicit build-status documentation for implemented versus planned capabilities.

**Status:** In progress.

**Tech:** `TypeScript` · `Cloudflare Workers` · `D1` · `Structured Data Pipelines`
